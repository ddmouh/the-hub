# PRD — Windows Desktop Companion (تسمية العمل)

> **النسخة:** 0.1 — مسودة أولى
> **التاريخ:** 2026-09-14
> **الحالة:** موافقة معمارية أولية — قيد التطوير

---

## 1. الملخص التنفيذي

تطبيق **بيئة عمل متكاملة (All-in-One Workspace)** لسطح مكتب ويندوز، يجمع:
مساعد ذكاء اصطناعي بصلاحيات نظام، تخصيص سطح المكتب، ويدجتس عملية،
مشغّل تطبيقات دائري، Workspaces، وDynamic Bar — في **منتج واحد مترابط** بدل
مثبت 5–10 برامج منفصلة.

**الموقف التسويقي:**
> ليست "مجموعة برامج موجودة"، بل **منظومة Desktop Experience** —
> كل ميزة تفهم الأخرى وتعمل معها.

**الكل في جملة:**
> طبقة فوق ويندوز تحوّل سطح المكتب إلى بيئة أذكى وأسرع وأنظف، بدون ثقل.

**الأولويات الأساسية (بالترتيب):**
1. الأداء (Performance)
2. الاعتمادية (Reliability)
3. سهولة الاستخدام (Usability)
4. التخصيص (Customization)
5. الرسوميات/الأنيميشن (Animations) — **الأخيرة**

---

## 2. المشكلة والفرصة

### المشكلة
- مستخدم الويندوز عنده تبعثر: launcher + widgets + خلفية متحركة + أداة تنظيم + مساعد AI = **برامج كثيرة، إعدادات متكررة، وتعارض أحياناً**.
- أغلب الحلول الحالية: إمّا ثقيلة (كروميوم/Electron)، أو قبيحة، أو غير قابلة للتخصيص، أو تركز على ميزة وحيدة.

### الفرصة
- منتج واحد يجمعها **بهدف "المنظومة"**: الميزة الحقيقية هي التكامل بين الأجزاء،
  مو أي ميزة منفردة.
- مثال التكامل: المستخدم يقول للـ AI "ناوي ألعب" → الـ AI يختار Workspace Gaming
  → يفتح الألعاب + يطبق الوضع + يوقف الخلفية المتحركة + يغير الـ Dynamic Bar.
- لا يوجد لاعب مهيمن في هذه المساحة اليوم على ويندوز.

---

## 3. المستخدم المستهدف

| الشخصية | الوصف | احتياجه الأساسي |
|---|---|---|
| **اللاعب** (أولوية) | PC للإلعب/الستريمينق | سرعة فتح، إيقاف أي ثقل أثناء اللعب، مواقيت صلاة |
| **صانع محتوى/محترف** | تعديل فيديو، برمجة، شغل | Workspaces + ويدجتس إنتاجية |
| **مستخدم إنتاجية** | طالب/موظف | تنظيم، تذكيرات، واجهة هادئة |
| **محب التخصيص** | يهوى تجميل الديسكتوب | خلفيات، Taskbar، Widgets واسعة |

**السوق الأساسي:** اللاعبون + محبو التخصيص (القطاع العربي الأدنى للتوزيع أولاً).

---

## 4. هوية المنتج

- **العنوان:** Desktop Companion — (الاسم التجاري النهائي يُحدد لاحقاً، يُقترح ما يكون طويلاً).
- **الوصف بالعربي:** تطبيق شامل للويندوز يحوّل سطح المكتب إلى بيئة أذكى وأسرع،
  بدمج AI بصلاحيات فعلية، Widgets، تخصيص، Launcher، Workspaces، وDynamic Bar
  في تجربة واحدة خفيفة وعملية.
- **لا يكون:** أداة "Themes Engine" ولا "Chatbot في نافذة".

---

## 5. الركائز الخمس

### 5.1 المشغل الدائري الخاطف — Radial Launcher

**الوصف:** قائمة دائرية تنبثق تحت مؤشر الفأرة **بالزر الأوسط**، بحركة
**Hold & Flick** (سحب سريع نحو التطبيق ثم إفلات) لفتحه خلال أجزاء من الثانية.

**المتطلبات الوظيفية:**
- تفعيل: الضغط مع الاستمرار على الزر الأوسط يفرد العجلة، السحب والإفلات ينفذ،
  الزر بدون سحب = بحث فوري.
- إدارة التطبيقات: إضافة/حذف/ترتيب/مجلدات/اختصارات.
- تخصيص الشكل: نصف القطر، الحجم، الأيقونات، الزوايا.
- كل وحدة تتصل بشريط البحث (بحث تطبيقات + ملفات + ويب).
- **الحد الأدنى للأداء:** ظهور العجلة ≤ 150ms، بلا أنيميشن مبالغ.

**معايير القبول (Beta 0.1):**
- زر أوسط يفتح العجلة تحت المؤشر على أي شاشة (متعددة الشاشات).
- فتح تطبيق حقيقي بسحب وإفلات أقل من 0.8 ثانية.
- لا يظهر أي وميض/تأخر عند 60 إطاراً على نظام متواضع.

---

### 5.2 مساعد ذكاء اصطناعي بصلاحيات نظام — System AI

**الوصف:** ليس دردشة، بل **Computer Assistant**: يحلل سياق الشاشة وينفذ
أوامر فعلية (Tool Calling) عبر صلاحيات يديرها المستخدم.

**الأوامر النموذجية:**
- "افتح Discord وSpotify وChrome" → تنفيذ مباشر.
- "جهزني للجيمينج" → يطبق Workspace Gaming.
- "رتب سطح المكتب" → ينظم الأيقونات/الشاشات.
- "شن استهلاك الجهاز" → يقرأ ويعرض البيانات.

**المتطلبات الوظيفية:**
- كتالوج أدوات (Tool Catalog) بنماذج JSON لكل أداة:
  فتح/إغلاق تطبيقات، تحكم صوت/سطوع، تغيير خلفية، تشغيل اختصارات،
  قراءة النظام (CPU/RAM/مروحات)، إدارة ملفات (قراءة/نقل).
- **محلي افتراضياً عبر Ollama** (نماذج جيدة بالعربي: Qwen / Llama)،
  مع خيار **سحابي اختياري** (OpenAI / Claude / Google) للمستخدم الذي يوافق.
- تدفق تأكيد للمهام الحساسة (انظر القسم 6).
- **لا يصغي للمايكروفون افتراضياً** — الدخول من الاختصار / الكتابة فقط ما لم يُفعَّل.

**معايير القبول (1.1 بعد الأساسيات):**
- 90% دقة في تنفيذ قائمة أوامر محددة (20 أمراً مرجعياً).
- أي أمر خطأ يوقفه فوراً مع رسالة واضحة، ولا يقوم بعمليات جزئية ممنوعة.
- تعمل بدون إنترنت على نموذج محلي.

---

### 5.3 Workspaces / Categories — الفئات المتزامنة

**الوصف:** تشغيل حزمة برامج + إعدادات + شكل سطح المكتب **بضغطة واحدة**.
ليست مجرد مجلد — إنها **حالة** كاملة.

**أمثلة:**
| Workspace | التطبيقات | الإعدادات المرفقة |
|---|---|---|
| Gaming | [اللعبة] + Discord + Spotify + OBS | خلفية خاصة + إيقاف الرسوميات + إخفاء ويدجتس ثقيلة |
| Work | Chrome + Notion + Discord + Spotify | وضع Dark + أيقونات مرتبة |
| Study | Chrome + PDF + Notes + Spotify | Do Not Disturb + Pomodoro |
| Editing | DaVinci Resolve + Discord + Chrome + Files | خلفية ثابتة + ويدجتس النظام |

**المتطلبات الوظيفية:**
- حفظ: قائمة تطبيقات + شروط إطلاق (فتح في شاشة معينة) + إعدادات تشغيل.
- إنشاء/تعديل وحذف وتصدير/استيراد الـ Workspaces.
- **تلقائي ذكي (Smart Trigger):** "عند تشغيل X → طبّق Workspace Y" (اختياري وقابل للتعطيل).
- زر "Launch Workspace" + أيضاً من الـ AI باللغة الطبيعية.

**معايير القبول (إصدار 1.0):**
- تشغيل 5 تطبيقات في وقت متزامن في ≤ 3 ثوانٍ إجمالاً على جهاز متوسط.
- حفظ شكل كامل (خلفية + ويدجتس + Taskbar) واستعادته بدقة.

---

### 5.4 الشريط التفاعلي العلوي — Dynamic Island / Dynamic Bar

**الوصف:** كبسولة ذكية أعلى الشاشة تعرض بيانات مختصرة عند الحاجة ثم تنكمش،
وتتوسع حسب نوع الحدث.

**الأحداث المدعومة (Beta):**
- تشغيل وسائط (موسيقى/فيديو): اسم + تحكم Play/Pause/Next + شريط تقدم.
- USB مُوصل / مقطوع.
- تنزيل ملف (النسبة).
- نسخ إلى Clipboard.
- تغيير الصوت (عرض لحظة ثم اختفاء).
- مؤقت/Pomodoro عدّاد مباشر.
- إشعارات موحدة بدل الـ Notification المزعجة.
- حالة البطارية/الـ CPU عند الاقتضاء.

**السلوك:**
- تتوسع حسب الحدث، ثم تنكمش لشريط صغير.
- يُخصِّص المستخدم: الموقع (أعلى الوسط يمين/يسار)، ما يظهر وما لا،
  ومدة بقاء كل نوع حدث.

**معايير القبول (Beta 0.1):**
- أي حدث وسائط يفتح الكبسولة < 200ms.
- إلغاء التمركز أو العكس، زوم ثابت بلا Lag عند كثرة الأحداث.

---

### 5.5 التخصيص والمظهر — Widgets & Wallpapers & Taskbar

#### Widgets (فئات مقترحة — المكتبة قابلة للتوسع عبر الإضافات)
| الفئة | الأمثلة |
|---|---|
| أساسية | Clock، Calendar، Weather، CPU/GPU، RAM، Storage، Network |
| إنتاجية | To-do، Notes، Pomodoro، Countdown، Reminders، Clipboard History |
| وسائط | Spotify، YouTube Music، Currently Playing |
| جيمينق | FPS، GPU/CPU Temp، Ping، Game Timer |
| إسلامية | مواقيت الصلاة، الصلاة القادمة، القبلة، التاريخ الهجري، أذكار |
| سريعة | Quick Actions (Wi-Fi، بلوتوث، صوت، سطوع، لقطة، Mic، DND، Lock) |

- كل ويدجت = **نافذة مستقلة قابلة للموضع/التحجيم/الشفافية**.
- خيار "وضع خفيف" لإيقاف كل ويدجت غير الضرورية بضغطة واحدة.

#### Wallpapers
- أنواع: ثابتة، GIF، فيديو، ديناميكية (حسب الوقت)، Dark/Light تلقائي.
- **قاعدة صارمة — تتوقف الرسوميات كلياً عند:**
  ملء الشاشة (ألعاب)، تبديل شاشة العرض، وضع البطارية، درجة حرارة/استهلاك عالي.
- خيار تعليق الدقة/الـ FPS حسب مستوى الطاقة.

#### Taskbar
- إخفاء كلي/جزئي، شفافية، Blur، تحجيم، سلوكيات (تركيز تلقائي)،
  وسين خاص بالجيمينق (إخفاء عندما يفتح لعبة).

#### Desktop
- إخفاء/تنظيم الأيقونات، Grid/Free placement، تأثيرات بسيطة، تحسين المساحات.

**معايير القبول (Global 1.0):**
- إيقاف كل الرسوميات عند فتح أي لعبة ملء شاشة في ≤ 300ms.
- ويدجت غير نشطة لا تستهلك أكثر من 5MB RAM.
- تعطيل أي ميزة = صفر تأثير على باقي الميزات.

## 6. نظام الصلاحيات — AI Permissions

| المستوى | الأمثلة | السلوك |
|---|---|---|
| **0 — آمن (افتراضي)** | فتح تطبيقات، قراءة النظام، بحث، تغيير ويدجت | تنفيذ مباشر |
| **1 — متوسط** | إغلاق تطبيقات، تحكم صوت/سطوع، تغيير خلفية | تنفيذ مع سجل (Log) |
| **2 — حساس** | حذف ملفات، تغيير ملفات النظام، تشغيل سكربتات | موافقة بشرط (Confirm) |
| **3 — خطير (معطّل افتراضياً)** | مسح، تثبيت، أوامر Admin | ممنوع حتى يُفعَّل يدوياً |

- شاشة صلاحيات واضحة لكل فئة (مثل صلاحيات الموبايل).
- **جلسة تأكيد مؤقتة:** موافقة على مهمة معيّنة تظل ذاكرة لفترة قصيرة فقط.
- سجل تدقيق (Audit Log) قابل للعرض للمستخدم لكل ما نفذه الـ AI.
- "زر إيقاف طوارئ" عام يعلّق كل سلوكيات الـ AI فوراً.

## 7. التصميم — Design System

**المبدأ:** يندمج مع ويندوز، لا يبدو كموقع فوق ويندوز.

### Anti-patterns (ممنوع)
- Gradients متعددة، ألوان بنفسجية/زرقاء مبالغ فيها، Glow.
- Cards مفرطة، نصوص ضخمة (تبدو Dashboard)، أنيميشن عند كل ضغطة.
- أي واجهة "تُلمس ولاتجاوب" (غير تفاعلية فعلياً).
- أي شكل يبدو مولّداً من "AI Website" تجميلي من غير وظيفة.

### Design Tokens (أولية)
| Token | القيمة |
|---|---|
| الخلفيات | أسود/رمادي/أبيض حسب الوضع، Acrylic/Blur عند الحاجة فقط |
| Accent | لون واحد يُقرأ تلقائياً من سمة النظام (Windows) |
| الخط | خط النظام (Segoe UI Variable) — بلا خطوط خارجية |
| الأيقونات | بسيطة موحدة (Flaticons ثابتة/مخصصة) |
| الحواف | Borders 1px خفيفة، زوايا 8-12px |
| الظلال | خفيفة، غير لامعة |
| المدة الزمنية | كل الأنيميشن ≤ 120ms، تفضيلاً صفراً القد الداخل |
| كل واجهة | عناصر قليلة وتفاعلية 100% بلا زخرفة |

### مبدأ "العناوين المختصرة"
كل زر/عنوان = كلمة أو كلمتان أقصى، واضحة المعنى (مثال: "Gaming" لا "وضع الألعاب الذكي").

## 8. الأداء والاعتمادية — المطالب غير الوظيفية

| المعيار | الهدف |
|---|---|
| استهلاك RAM (وضع خامل) | Core ≤ 80MB، كل وحدة عبر الإدارة المستقلة |
| استهلاك CPU (خامل) | ≤ 0.5% تقريباً، والـ Wallpaper صفر عند ملء الشاشة |
| زمن فتح العجلة | ≤ 150ms |
| زمن الكبسولة | ≤ 200ms |
| ترقية البرنامج | تثبيت/تحديث بدون فقد إعدادات |
| عدم الانهيار | تعطل وحدة = إعادة تشغيلها ذاتياً، **التطبيق لا يموت** |
| حالة الطوارئ | تعطيل كامل للميزة من الإعدادات ثم إعادة تفعيل بنظافتها |

**مبدأ الاعتمادية:** "جزء من النظام، لا برنامج ثقيل فوق النظام".
أي ميزة تسبب Lag = تُعتبَر فاشلة حتى لو أجمل.

## 9. البنية التقنية — Architecture

### اختيار التقنية
- **C# / .NET 8 + WPF (WinUI 3 بديل عند الحاجة للـ Mica الإضافي).**
- السبب: تكامل ويندوز عميق (هوك الفأرة، ملء الشاشة، Taskbar، DWM)، استهلاك قليل، نضج أدوات.
- البديل: توري 2 (Rust + WebView) فقط لمن يفضّل واجهات الويب — مرفوض افتراضياً للثقل.

### النموذج: تطبيق واحد من طبقتين (Hub + Services)

**Layer A — نافذة التحكم (Template Hub):**
ما يراه المستخدم = **برنامج واحد** له تري واحد ونافذة رئيسية واحدة بـ **Sidebar**:
```
نافذة التحكم الرئيسية (Sidebar)
 ├── AI Assistant      (شات + تنفيذ أوامر)
 ├── الـ Widgets       (تصفح + تركيب + تخصيص)
 ├── Wallpapers
 ├── Taskbar / Desktop الإعدادات
 ├── Workspaces
 └── Launcher إعدادات
```

**Layer B — بيئة التشغيل (Overlay Services):**
خدمات خفية **خارج نافذة الـ Hub** تظهر على سطح المكتب زمان الاستخدام فقط:
```
 ├── Radial Launcher  (يظهر تحت مؤشر الفأرة)
 ├── Dynamic Island   (جزيرة أعلى الشاشة)
 ├── الـ Widgets الفعالة على الديسكتوب
 └── Wallpaper Engine (عملية رسوميات منفصلة)
```
> لماذا؟ العجلة/الجزيرة/الويدجتس لا تعيش "داخل نافذة" — هي Overlays فوق السطح.
> لكن **المستخدم لا يدرك التقسيم**: تري واحد + نافذة وحدة + تثبيت واحد.
> عزل العمليات خدعة هندسية للاستقرار (لا ينهار التطبيق)، ليست خياراً ظاهراً للمستخدم.

### تفاصيل العمليات (Crash-Isolated)
```
Core (عملية رئيسية خفيفة)
 ├── Tray + هوت كيز + Orchestrator + الإعدادات + Shared Settings
 ├── Named Pipes لربط الخدمات
 ├── (خدمة 1) Radial Launcher  ← نافذة Overlay
 ├── (خدمة 2) Dynamic Island   ← نافذة Overlay
 ├── (خدمة 3) Widgets Engine   ← نوافذ Overlay مستقلة
 ├── (خدمة 4) AI Assistant     ← تحميل كسول (ثقيل عند الاستخدام فقط)
 └── (خدمة 5) Wallpaper Engine ← عملية رسوميات مستقلة (يتوقف في الألعاب)
```
- الـ **Hub (Layer A)** يتواصل مع الخدمات عبر نفس الـ IPC ليعرض حالتها وضبطها.
- كل خدمة تفتح نافذتها (Overlay) عند التفعيل، وترسل Heartbeat دورياً.

### التواصل بين العمليات
- Named Pipes + JSON-RPC (بروتوكول نصي بسيط، قابل للفحص).
- كل عملية ترسل Heartbeat دورياً؛ Core يعيد تشغيل الوحدة الميتة.
- لا توجد وحدة تعتمد على أخرى للبقاء — كلها اختيارية.

### تخزين البيانات
- SQLite للإعدادات/الـ Workspaces/سجل الصلاحيات وسجل الأداء.
- لا تكتب في مجلدات النظام خارج حدودها المعتادة.

### تكامل النظام
- هوك Win32 (LowLevelKeyboard / Mouse) للـ Hold & Flick — مع نظام تنازلات
  لا يسرق اختصارات التطبيقات الأخرى.
- كشف ملء الشاشة: مراقبة النافذة النشطة + الإعلام عبر SetWinEventHook،
  وإطارات زمنية ≤ 300ms للتعطيل.

### المكوّن الذكي (AI)
- محلي: **Ollama** (نماذج عربية جيدة: Qwen / Llama عربيّ).
- سحابي: OpenAI / Claude / Google (اختياري، بموافقة المستخدم).
- تنفيذ الأوامر: **Tool Calling** — الـ Core يتحقق من الصلاحية ثم ينفذ في
  معزل عن نموذج اللغة (لا يُتاح للنموذج مباشرة إلا وصف أداة + schema).
- Caching للنتائج المتكررة لخفض استهلاك الجهاز.

## 10. قابلية التوسع — Model الإضافات (Plugin API)

- **SDK بواجهات عامة** على مستوى: جديد ويدجت، نوع خلفية، أداة AI جديدة،
  Skin للعجلة، محرك بحث.
- أي إضافة = وحدة مستقلة منفصلة، تصريح صلاحيات صريح (Manifest).
- متجر إضافات مقترح للمرحلة 2.0 (مع تمييز Mod / Paid).
- لا تتطلب الإضافات إعادة برمجة الـ Core.

**شرط صارم:** إضافة مكسورة توقف نفسها فقط، لا التطبيق، ولا تصل لبيانات
المستخدم دون أذن ممنوح في الـ Manifest.

## 11. الخصوصية والأمان

- الافتراضي Local-first: بيانات محلياً، لا اشتراك إرسال بيانات بدون إذن.
- الـ AI الافتراضي محلي (Ollama) — الصوت/اللوحة لا تصل خدمة خارجية.
- خاصية "وضع صارم": يعطّل كل وصول للمايكروفون/الشبكة للـ AI كلياً.
- التحديثات موقّعة توقيعاً رقمياً، ومصادر إضافات معروفة فقط.
- مهاتفة كل "فعل" سجله في Audit Log.
